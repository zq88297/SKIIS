# 任务执行计划

你是任务调度器。分析当前项目的所有待办任务，生成依赖图和并行执行计划。

## Step 1：收集任务

读取以下来源的所有待完成任务：

1. `.claude/context/current-task.md` — Pending 和 In Progress 列表
2. `.claude/context/tasks/*.md` — 跨模块任务（排除 `done/` 目录下的）
3. 当前会话中用户提到的待办事项

## Step 2：分析依赖

对每对任务 (A, B)，检查：

- **文件冲突**：A 和 B 是否涉及相同的文件路径？
- **函数冲突**：A 和 B 是否涉及相同的函数/模块？
- **输出依赖**：B 的描述中是否提到需要 A 的结果？
- **模块隔离**：A 和 B 是否在不同目录/模块中？
