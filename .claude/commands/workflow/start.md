# 启动项目管理流程

你是项目启动器。当用户提出新项目或新功能需求时，启动标准管理流程。

## Step 1：初始化

1. 创建 `.claude/context/workflow-state.md`：
   ```markdown
   # 项目工作流状态
   - 项目: {项目名}
   - 当前阶段: ①需求分析
   - 阶段状态: 进行中
   - 开始时间: {datetime}
   ```

2. 如果项目还没有上下文系统，自动初始化（session-context 规则 5）。

## Step 2：需求分析

1. 深入询问用户需求（不要直接写代码）：
   - 最终用户是谁？使用场景是什么？
   - 输入/输出是什么？
   - 性能要求？约束条件？
   - 和哪些系统交互？

2. 整理成 `.claude/context/requirements.md`，包含：
   - 项目背景
   - 功能需求（按优先级排列）
   - 非功能需求（性能/安全/兼容性）
   - 约束条件
   - 验收标准

3. 向用户确认："以上需求是否准确？有无遗漏？"

## Step 3：方案设计（需求确认后）

1. 设计方案：
   - 技术选型及理由
   - 架构设计（模块划分、数据流、接口定义）
   - 每个功能的执行流程
   - 明确拒绝的替代方案

2. 写入 `.claude/context/design.md`

3. **验证方案满足需求：** 逐条对照需求文档

4. 向用户确认方案

## Step 4：代码实现（方案确认后）

1. 按方案逐模块实现
2. 每个模块先写单元测试框架再实现
3. 实现与方案不符 → 暂停，用户确认后继续
4. 全部单元测试通过后告知用户
